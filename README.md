# Road Rush 🏎️⚡

A fast-paced 2D arcade car racing game built entirely with **HTML5**, **CSS3**, and **Vanilla JavaScript** — zero external frameworks or dependencies!

![Road Rush](https://img.shields.io/badge/Road%20Rush-v1.1.0-blue.svg)
![Vanilla JS](https://img.shields.io/badge/Tech-Vanilla%20JS-yellow.svg)
![Status](https://img.shields.io/badge/Status-Active%20Development-success.svg)

---

## 🎮 Features

- [x] **Player Movement & Handling**: Responsive 3-lane navigation.
- [x] **Enemy Traffic**: Dynamic procedural traffic with scaling difficulty.
- [x] **Collision Detection**: Precise hitbox detection with visual impact states.
- [x] **Coin Collection System**: Collect spinning gold coins for score boosts.
- [x] **Nitro Boost & Traffic Smash**: Charge your NOS gauge to engage turbo speed, flaming exhaust trails, and smash safely through enemy cars for massive bonus points!
- [x] **Responsive Desktop & Mobile Controls**:
  - **Desktop**: `Arrow Keys` or `WASD` to steer &bull; `Space` or `Up Arrow` for Nitro Boost &bull; `Esc` to Pause.
  - **Mobile**: On-screen steering touch buttons, swipe gestures, and dedicated touch Nitro boost button.
- [ ] Persistent LocalStorage Statistics *(Coming Soon)*
- [ ] Car Garage & Customization *(Coming Soon)*
- [ ] Procedural Web Audio Engine *(Coming Soon)*
- [ ] Day/Night & Weather Cycles *(Coming Soon)*

## 🛠️ Tech Stack

- **Markup**: HTML5 Semantic Elements
- **Styling**: CSS3 (Custom Properties, Keyframe Animations, Flexbox, CSS Grid)
- **Logic**: Vanilla JavaScript (ES6+ Modules, Delta-time `requestAnimationFrame` loop)

## 🚀 How to Run Locally

1. Clone or download this repository:
   ```bash
   git clone https://github.com/your-username/Road_Rush.git
   ```
2. Open `index.html` directly in any modern web browser or serve via Live Server:
   ```bash
   # With VS Code Live Server or python
   python -m http.server 8000
   ```
3. Hit **START RACE** and hit the road!
